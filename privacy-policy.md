# PocketStickers Privacy Policy

Last updated: 2026-06-13

PocketStickers is a local-first sticker library for iPhone and Messages.

## Data Collection

PocketStickers does not require an account and does not collect personal data for core sticker creation, organization, search, or sending.

## Sticker Content

Stickers, source images selected by the user, generated thumbnails, metadata, collections, favorites, notes, and usage counts are stored locally on the device. PocketStickers mirrors the sticker index and required sticker assets into the app's local App Group container so the Messages extension can display and send saved stickers.

## Photos, Camera, And Files

Photos, Camera, and Files access are used only when the user chooses those sources for sticker creation, import, backup, restore, or sharing. PocketStickers does not scan the user's library in the background.

## Network, Accounts, And Tracking

PocketStickers v1 does not require network access for core flows, does not include a backend account system, does not include ad SDKs, and does not track users across apps or websites.

## Sharing

PocketStickers does not upload sticker content for core flows. If the user exports, backs up, restores, or shares a local archive, that action is initiated by the user through iOS system interfaces.

## Children

PocketStickers is not designed to collect personal information from children. The app does not include accounts, social features, public profiles, or a public sticker marketplace in v1.

## What To Include

When requesting help, include:

- Device model and iOS version.
- PocketStickers app version and build number.
- Whether the issue happened in the main app or Messages extension.
- The source used for sticker creation, such as Photos, Camera, Files, or an existing transparent image.
- Any visible error message.

## Common Questions

### Do I need an account?

No. PocketStickers v1 works without an account.

### Are my stickers uploaded?

No. Core sticker creation, organization, search, and sending are local-first. The Messages extension reads the local shared App Group index generated by the app.

### Why does PocketStickers ask for Photos, Camera, or Files access?

PocketStickers uses those permissions only when the user chooses to import or capture a sticker source.

### Why does the Messages extension need App Group access?

The App Group lets the main app and Messages extension share the local sticker index and sticker assets on the device.
